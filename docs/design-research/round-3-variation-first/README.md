# 第3回デザイン調査 — Variation First

調査日: 2026-08-02

第2回の06「一枚の写真」は、余白と情報量の参考として好感触だった。ただし第3回では、その構図を中心に派生案を量産しない。写真分割は20案中の1案だけに留め、**ホームの主役・一覧構造・文字の性格・画像の役割が異なる20方向**を比較する。

## 今回の結論

- 06から引き継ぐのは「最初の画面に置くものを絞る」「余白に役割を持たせる」という判断であり、写真そのものではない。
- 20案は、5つの設計家族に4案ずつ分けた。見た目の色替えではなく、記事の探し方や読み始め方から変えている。
- 現時点で一案に決めない。まず幅のある20案を確認し、好き・嫌いの理由を取ってから、3案だけ実データでlocalhostへ組む。
- 推奨ショートリストは、01「本の余白」、05「編集索引」、13「日本語ポスター」。09「一枚の写真」は比較用として残す。

比較用モックは方向確定後に削除した。以下は文章による比較履歴である。
