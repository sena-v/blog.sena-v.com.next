# ブログデザイン調査 第2回 — 年表を使わない

調査日: 2026-08-02

## やり直した理由

第1回は、縦線と点の年表を残すこと、ホームに全37件を置くことを先に決めた。その結果、配色や書体を変えても、どの案も「年・日付・題名が大量に並ぶ画面」になり、ごちゃごちゃして見えた。

第2回は、年表をいったん完全に外した。過去記事を消すのではなく、ホームと保管庫の役割を分ける。

- ホーム: 今読む入口を3〜6件だけ見せる
- `/writings`: 全37件を検索・タグ・並び替えできる保管庫にする
- 記事: 読むことへ集中する
- About: ポートフォリオ性を副次的に持たせる

## 結論

現時点の第一候補は、**01「静かな一段組」**を基本構造にし、**04「今月の窓」**の掲載件数ルールを使う案である。

```text
ホーム
├─ 小さなサイト名と本人の2文
├─ 最新記事 4件（概要は最新1件だけ）
├─ 代表して読んでほしい記事 2件（題名だけ）
└─ 記事一覧 / About / GitHub / Qiita / RSS
```

これならブログが主役で、転職用の説明を常設せず、ホームの情報量を現在の半分以下にできる。写真や強い書体は、基本構造を実ブラウザで確認してから足す。
