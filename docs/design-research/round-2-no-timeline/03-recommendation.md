# 第2回の推奨構成

## 推奨

**01「静かな一段組」を構造に、04「今月の窓」の件数制限と、10「素のWeb」の直接性を使う。**

見た目を三案分混ぜるのではなく、役割を分担させる。

- 01: 幅、文字、余白、記事の見せ方
- 04: ホームへ出す件数とフォールバック規則
- 10: ボタンや箱に変換せず、通常リンクとして置く姿勢

## 推奨ホーム

```text
sena-v.
技術について試したことと、あとで読み返したいことを書いています。

最新の記事
数年止まったNext.jsブログを、履歴を残して再構築した
  導入2行だけ

使用したことのないパッケージマネージャーを比較してみた
JavaScriptバージョンを全部見返してみる
2023年振り返り

すべての記事を見る

このブログについて  GitHub  Qiita  RSS
```

### 情報量

- 最新4件
- 概要1件
- 本人紹介1〜2文
- ナビゲーション4項目
- 写真0点
- タグ0件
- 常設数値0件

記事が当月に1〜4件ある場合は当月分だけ出す。0件なら最新4件へ戻す。更新頻度が上がって当月5件以上になった場合も4件で切り、全件一覧へ送る。

## 推奨記事一覧

ホームとは別の「探す画面」と割り切る。

- 見出し: `記事を探す`
- 検索
- `新しい順 / よく読まれている順`（人気順はGA4準備後）
- タグは初期状態で全展開せず、選択または検索結果の補助にする
- 一覧行は題名を主役にし、日付は小さくする
- 外部記事は`Qiita ↗`のように文字で示す
- 概要は検索結果または最新数件だけでもよい

## 推奨About

ホームを静かにする代わりに、Aboutは次を持つ。

1. いま何をしているか
2. 何について書くか
3. このブログを再開・改修したこと
4. 代表して読んでほしい記事2〜3本
5. GitHub、Qiitaなど

ポートフォリオらしいProjects、Skills、数値カードは作らない。採用側はAboutと代表記事から必要な情報へ進める。

## 推奨記事ページ

- 最大幅は日本語32〜40字/行から実測
- 記事題名、公開日、必要なら更新日、本文
- タグは題名直下に大量表示せず、末尾または補助位置
- 目次は長文だけ
- 関連記事は最大2件、題名リンクのみ
- 記事内の「課題と方針」の年表表現は本文固有の図として残してよい。サイト全体のナビゲーションには使わない

## 色と文字の決め方

第1段階はシステムフォントとモノクロで組む。その状態で情報量を承認してから、次の比較を行う。

### 色

1. 白 + 墨 + 青墨
2. ごく薄い灰 + 墨 + 深緑
3. 生成り + 墨 + 暗い朱

### 文字

1. 日本語はシステムサンセリフのみ
2. 本文はシステムサンセリフ、見出しだけ明朝1ウェイト
3. 日本語はシステム、英数字だけ小さな表示書体

日本語Webフォントを本文全体へ使う案は初期候補にしない。

## localhostで比較する上位案

画像選定後も、いきなり完成CSSを作らない。次の3案を同じ実データでHTML化すると判断しやすい。

1. 01 + 04 + 10の推奨案
2. 03「表紙と目次」
3. 06「一枚の写真」（使える本人写真がある場合だけ）

同じ1440pxと390pxで並べ、次を比較する。

- 最初にどの題名を読みたくなるか
- スクロール前の要素数
- Aboutへ行かなくてもブログだと分かるか
- モバイルで読む順序が自然か
- 写真・書体を外しても成立するか

## 実装工程

### Phase 1 — モノクロHTML

- 現在のホームをbeforeとして保存
- 推奨案、03、必要なら06を実データで作る
- CSSは幅、余白、文字サイズ、罫線だけ
- localhostでPC・モバイル比較

### Phase 2 — 方向決定

- 一案に絞る
- 不要だった要素と理由を記録
- Aboutと記事一覧の優先順位を確定

### Phase 3 — 視覚言語

- アクセント色3候補
- 見出し書体2候補
- リンク、フォーカス、罫線
- 写真案なら本人素材を選ぶ

### Phase 4 — 全画面適用

- ホーム
- 記事一覧
- 記事
- About
- タグ、Privacy、404

### Phase 5 — AI脱臭・性能・A11y

- 抽象語、英大文字ラベル、均一な文長を再確認
- 角丸、影、ピル、面の用途を監査
- 320px、200%拡大、キーボード、Reduce Motion
- LCP、INP、CLS、JS/CSS/フォント量をbeforeと比較

## 判断を保留するもの

- ダークモード
- 本人写真
- 日本語Webフォント
- 人気順
- 記事種別の追加
- アートディレクション記事

これらは基本構造が静かに成立してから一つずつ判断する。
