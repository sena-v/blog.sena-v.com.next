# 第2回コンセプト画像の生成記録

作成日: 2026-08-02

## 共通条件

- モード: built-in image generation / 新規生成
- 用途: 情報量とホーム構造の比較用UIモックアップ
- サイズ意図: 1440×1024前後のデスクトップ画面、ブラウザ枠なし
- 既存サイトや調査サイトを模写しない
- 年表、縦線と点、年別グループ、ホーム全件表示を禁止
- ホームの記事数は3〜6件
- 共通禁止: Bento Grid、3枚カード、数値パネル、CTAボタン2個、紫青グラデーション、ガラス、発光、巨大な角丸、ストックイラスト、偽ターミナル、記事ごとの生成サムネイル
- 画像内の日本語は視覚比較用。実装時はHTMLへ置き換える

## 実装時の扱い

1. 画像内の文字組みをCSSで完全再現しようとしない
2. 同じ実記事4件を入れたHTMLで密度を再評価する
3. 画像に偶然できた装飾を仕様にしない
4. 写真案だけ本人所有の素材へ差し替える
5. 上位案は390px幅も実装してから選ぶ
