# モックアップ生成条件

## 目的

第3回10と11に共通する「本人素材を編集して見せる」原理を、異なる情報構造へ展開した20案を比較する。生成画像は完成デザインでも、本番素材でもない。

## 共通プロンプト条件

- 1536×1024相当、16:10に近いデスクトップWebサイトの正面スクリーンショット
- `sena-v.com` の日本語個人ブログ
- 主役は記事と本人所有を想定した資料。ポートフォリオのProjects/Skills/metricsは置かない
- 実在人物、企業ロゴ、既存サイトの複製を避ける
- 角丸カード群、ガラス、グラデーション、抽象3D、偽のテープ、ポラロイド、過剰な影を避ける
- 写真・ノート・コードは仮素材であり、本人が所有する素材に見せかけない
- 記事題名は共通して次を利用: 「ブログを作り直している」「GA4のpage_viewを一度だけ送る」「古い記事をどう残すか」「Next.jsを更新した記録」
- ナビゲーション: `記事 / 外部で書いたもの / このブログについて`
- 読めない大量の本文を生成せず、タイトル、日付、短い注記だけを画面に置く
- 実装可能なHTML/CSSの紙面。画像内にブラウザーやデバイスのモックアップを置かない

## 生成モードと扱い

- 使用: OpenAI `imagegen`
- モード: 新規生成。既存の10・11は画像参照として投入せず、言語化した構成原理だけを渡す
- 各案を別プロンプトで生成し、構図を変える
- PNGを`mockups/`へ保存し、最後に同じ比率の比較シートを作る
- 生成結果の日本語は最終コピーではなく、構造と密度を見るための表示とする
