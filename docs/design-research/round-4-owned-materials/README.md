## この回の前提

- これはポートフォリオの実績一覧ではなく、個人ブログのホームを考える調査である。
- 写真や紙は装飾ではなく、記事の背景、観察、制作過程を伝える資料として使う。
- 本実装でAI生成写真、偽の手書き、ストック写真を本人素材の代わりに使わない。
- モックアップ内の写真や紙はレイアウト比較用の仮素材である。
- モックアップ内の日付、コード、記事本文、端末表示も仮であり、現行サイトの事実や実装を示すものではない。
- 年表、Projects、Skills、数値実績、均一なカード群は主構造にしない。
- 現段階ではCSSやコンポーネントを変更しない。
